# Deutsch Mid-A1 Interactive Learning App 🇩🇪

An interactive German language learning web app for mid-A1 learners. Built as a Progressive Web App (no server needed).

## Features
- 📖 **Book Mode** — Dual-page spread with vocabulary, grammar tables, and useful phrases
- 📺 **TV Mode** — Auto-play TTS flashcard slideshow (German/English/Arabic)
- ✍️ **Test & Solve** — Multiple-choice quizzes with instant feedback
- 🌍 **Translation Test** — Translate sentences DE↔EN↔AR in all directions
- 📚 **Reading Passages** — Mini-stories with comprehension questions
- 🚀 **Immersion Mode** — Auto-pilot through all content (hands-free learning)
- 📚 **Trilingual Glossary** — DE / EN / AR with star/save and audio
- 📊 **Progress Tracker** — JSON export/import across devices

## 20 Lessons Covering
Days 1-10 (Part 1): Accusative, Modal Verbs, Separable Verbs, Dative, TeKaMoLo, Past Tense  
Days 11-20 (Part 2): sein-Perfekt, Two-Way Prepositions, Subordinate Clauses, Imperatives, Comparatives, Reflexive Verbs

## How to Use
Open `index.html` in any modern browser. No server or installation needed.
